# Отчет об оптимизации кода
## Оптимизации логгера

- Было: 
    - полное сканирование и копирование всех заголовков запроса и ответа в map[string]string
    - использование стандартной production-конфигурации
    - избыточное хранение заголовков в responseWriter
- Стало:
    - выборочное логирование только ключевых заголовков (User-Agent, X-Forwarded-For, Content-Type)
    - отключение stacktrace для info-уровня
    - упрощенние encoder config
    - улучшение структуры responseWriter (использование только необходимых полей)
- Эффект: снижение потребления памяти на за счет:

    - Устранения ненужных аллокаций мап
    - Уменьшения количества копирований строк
    - Оптимизация конфигурации логгера


## Оптимизации хранилища (MemStorage)
Успешные оптимизации
Замена sync.Mutex на sync.RWMutex

- Было: 
  - блокировка на запись и чтение
  - оптимизация методов доступа
- Стало: 
  - раздельные блокировки: RLock() для операций чтения и Lock() для операций записи
  - устранено избыточное копирование данных
- Эффект: 
  - увеличение производительности
  - снижение времени выполнения операций чтения
