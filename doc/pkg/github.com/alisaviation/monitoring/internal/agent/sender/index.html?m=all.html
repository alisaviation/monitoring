func (*Sender) SendMetricsBatch ¶ 

func (s *Sender) SendMetricsBatch(ctx context.Context, metrics map[string]*models.Metric, key string) error

SendMetricsBatch sends a batch of metrics to the server in a single request. ctx is used for request cancellation. metrics contains the metrics to send. key is used for request signing. Returns an error if the send operation fails.
