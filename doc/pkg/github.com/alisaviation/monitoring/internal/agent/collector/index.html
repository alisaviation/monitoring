func UpdateMetricsBuffer ¶ 

func UpdateMetricsBuffer(metricsBuffer map[string]*models.Metric, metrics map[string]*models.Metric)

UpdateMetricsBuffer updates the metrics buffer with new metrics, handling counters specially. For counters, it adds the new value to the existing value in the buffer. For gauges, it replaces the existing value with the new one.
